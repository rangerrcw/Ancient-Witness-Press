SETUP ADDENDUM AND CHECKPOINT SCHEDULE

Constitutional planning step required before Surah 1. Frozen with the Constitution on 10 September 2026.

A. File formats (LibreOffice)

All project deliverables are Office Open XML: .docx (Writer) and .xlsx (Calc). No proprietary macros. No .doc / .xls legacy. Arabic text is stored as ordinary Unicode in the documents.

Arabic text is primary. English is a tool. Default set, used in this order when a matrix is required:

Extra translations may be added only when meaning splits, with the reason recorded. Translation choice will not be manipulated to favor a predetermined conclusion.

D. Depth rule

Every surah/checkpoint packet uses the same section headings in the same order (Constitution §XXVII). Empty sections state “No finding in this unit” rather than disappearing.

Verse intensity: full line-by-line at first occurrence of a doctrine, name, legal ruling, Bible-parallel narrative, apparent tension, or disputed Arabic word. Cluster formulaic or repetitive stretches and extract the pattern once.

No discovery will be invented to fill a category.
